## 1. Качество кода и баги

**Статус:** ✅ Найдены и исправлены

### Исправленные проблемы

#### Проблема — XSS-уязвимость в поиске
- **Где:** app.js (строка 77-81)
- **Серьёзность:** критично
- **Что было не так:** Функция `highlight()` вставляла пользовательский ввод напрямую в HTML через `innerHTML` без экранирования спецсимволов. Злоумышленник мог ввести в поиск вредоносный код.
- **Что сделано:** Добавлена функция `escapeHTML()` для экранирования символов `<`, `>`, `&`, `"`.
- **Проверено:** XSS-атака через поиск невозможна.

## 3. CSS и визуал

**Статус:** ✅ Найдены и исправлены

### Исправленные проблемы

#### Проблема — Шрифт загружался через @import (блокирующий)
- **Где:** index.css (строка 1) + все HTML-файлы
- **Серьёзность:** предупреждение
- **Что было не так:** CSS `@import url(...)` для Google Fonts блокировал рендеринг.
- **Что сделано:** Удалён `@import` из CSS. Добавлены `<link rel="preconnect">` и `<link rel="stylesheet">` во все 7 HTML-файлов. Шрифт теперь загружается параллельно.
- **Проверено:** Шрифт отображается корректно на всех страницах.

### Общие замечания

- `box-sizing: border-box` глобально — отлично
- CSS-переменные последовательно — отлично
- `:focus-visible` стили — отлично
- 3 адаптивных брейкпоинта (1024, 768, 480) — отлично

## 4. Ссылки и навигация

**Статус:** ⚠️ Частично исправлены

### Исправленные проблемы

#### Проблема — Ссылки-заглушки `#` в footer
- **Где:** все HTML-файлы (footer)
- **Серьёзность:** предупреждение
- **Что было не так:** 8+ ссылок вели на `#` — соцсети, доставка, возврат, адрес. При клике страница прокручивалась наверх.
- **Что сделано:**
  - Соцсети: теперь показывают уведомление «Скоро будет доступно»
  - Доставка/Возврат: показывают «Страница в разработке»
  - Программа лояльности: теперь ведёт на account.html
  - Адрес: превращён в текст (span), не ссылка
  - Все страницы обновлены

#### Проблема — «Политика конфиденциальности» — не ссылка
- **Серьёзность:** инфо
- **Статус:** оставлена как есть — требуется создание отдельной страницы privacy.html

### Нерешённые проблемы

#### Проблема — Кнопки «Подобрать корм» — заглушки
- **Где:** account.html (строки 114, 124)
- **Серьёзность:** инфо
- **Что не так:** Кнопки не имеют обработчика — при клике ничего не происходит.
- **Как исправить:** Добавить `onclick="window.location='catalog.html?animal=dogs'"` и `?animal=cats`
- **Сложность:** 5 мин
