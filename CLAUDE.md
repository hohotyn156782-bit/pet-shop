# Martin Moore — Зоомагазин

## Запуск
Статический сайт — открыть `index.html` в браузере или через http-server.

## Стек
- HTML + CSS + vanilla JS (без фреймворков)
- Шрифты: Google Fonts (Nunito)
- Lottie — анимация собаки в hero
- localStorage — корзина

## Структура
```
index.html            — главная (категории, хиты, отзывы, блог)
catalog.html          — каталог с фильтрами
product.html          — карточка товара
cart.html             — корзина + оформление
blog.html             — список статей
article.html          — отдельная статья
account.html          — личный кабинет + программа лояльности
index.css             — все стили (единый файл, 4000+ строк)
app.js                — основная логика (~310 строк)
products.json         — база товаров (32+ товара)
articles.json         — база статей (6+ статей)
products-fallback.js  — резервные данные товаров (если fetch не сработает)
articles-fallback.js  — резервные данные статей
фото для проекта/     — 60+ изображений
```

## Функционал
1. Главная — hero с Lottie-собакой, категории по животным, хиты продаж, отзывы
2. Каталог — фильтры по животному (собаки/кошки/птицы/грызуны), возрасту, категории
3. Карточка товара — описание, состав, питательность, отзывы
4. Корзина — полная логика оформления заказа
5. Блог — статьи с фильтрацией по тегам
6. Личный кабинет — профиль, программа лояльности
7. Поиск с автодополнением и исправлением опечаток
8. Бейджи: "Хит", "Скидка 20%", "New"
9. Toast-уведомления, прелоадер, кнопка "Наверх"
10. Анимированные счётчики (15000+ клиентов, 850+ товаров)

## Дизайн
- Светлая бежевая тема (только одна тема)
- Только русский язык
- Анимации: preloader, fade-in on scroll, button scale, Lottie hero, счётчики

## Данные
- Fallback-система: если JSON не загрузился — используются встроенные JS-файлы с данными

## Правила
- Язык общения: русский
- Не добавлять фреймворки
